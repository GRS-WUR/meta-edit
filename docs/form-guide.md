# Form guide

The guide to filling in the form is now a page on the website itself, opened with the
**Help** button in the form's menu bar:

**<https://grs-wur.github.io/meta-edit/help.html>**

Its source is [`public/help.html`](../public/help.html). Edit that file to change the
help text; it is published with the rest of the site when changes are merged into `main`.
